# paper_fragments/

LaTeX table fragments generated from `results/` by `scripts/make_paper_tables.py` (generated by scripts/make_paper_tables.py at code 73e2ea5, results as of commit 928092a).  Each file is one `tabular` (booktabs) with a comment header naming its sources and filters; wrap it in `table`/`caption` in the paper.  The header's code hash is HEAD when the generator ran (`-dirty` = uncommitted changes present; the generator's own changes land in the following commit); the results hash is the last commit that touched `results/`.  Macros used: `\meth`, `\diag`, `\rhoC`, `\rhoV`, `\TE`, `\LE`, `\nobs`, `\nf`.
