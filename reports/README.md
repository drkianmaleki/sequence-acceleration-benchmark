# reports/

One report per prompt of the redesign, named `REPORT_<prompt>.md` (REPORT_1 ... REPORT_8A, REPORT_8B, ...); each describes what that prompt changed and how it was verified.
Console logs of the quick and full pipeline runs quoted by the reports live under `logs/` (`REPORT_<prompt>_<quick|full>_run.txt`).
Every report starts with `**Report back**` and ends with its `Written to:` line (the absolute path the report was written to).
